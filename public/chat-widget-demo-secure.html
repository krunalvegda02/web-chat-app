Option 2: Server-to-Server Flow Demonstration

How this demo works:

When you click the chat button, the following steps occur instantly:

  1. MOCK BACKEND: This page simulates a secure backend making a POST request to your /api/v1/platforms/session-token endpoint.
  2. TOKEN GENERATION: Your server returns a secure, 1-time-use sessionToken.
  3. IFRAME LAUNCH: We embed the chat iframe using ONLY the session token (the API key is completely hidden!).
